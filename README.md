# Posh PicNic – mock-up (WS04)

Klikbare mock-up van het bestelsysteem van Posh PicNic, gemaakt met Streamlit.

- **Hoofdpagina** met de knoppen voor klanten en medewerkers
- **Menu's raadplegen** werkt (de tien standaardmenu's, met weekdag- en weekendprijs)
- De andere knoppen zijn nog niet uitgewerkt

## Lokaal starten

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Online zetten

1. Zet deze map in een GitHub-repository.
2. Ga naar share.streamlit.io, kies de repository en als hoofdbestand `app.py`.

De menu's en prijzen zijn fictieve voorbeelddata.
